# JSON Visualizer

A simple and interactive tool to visualize JSON data in a tree-like structure. This application allows you to load, visualize, and save JSON files easily. It supports both light and dark themes, with automatic theme switching based on your system preference.

**👉 You can use it directly in your browser here: https://kotyaradev.github.io/json-visualizer**

## Features
- Visualize JSON in a structured tree format
- Load, save and delete JSON data
- Support for light and dark themes
- Multi-language support (English, Russian)

## Usage
1. Copy and paste your JSON data into the textarea.
2. Click **Visualize** to see the data rendered as a tree.
3. You can expand/collapse objects and arrays.

## Installation

1. Clone the repository:
```bash
git clone https://github.com/KotyaraDev/json-visualizer.git
```
2. Install dependencies:
```bash
npm install
```
3. Run the application:
```bash
npm start
```

# Визуализатор JSON

Простой и интерактивный инструмент для визуализации данных JSON в виде структуры дерева. Это приложение позволяет загружать, визуализировать и сохранять файлы JSON. Поддерживает как светлую, так и тёмную темы с автоматическим переключением в зависимости от настроек вашей системы.

**👉 Вы можете использовать его прямо в браузере: https://kotyaradev.github.io/json-visualizer**

## Возможности
- Визуализация JSON в структурированном виде дерева
- Загрузка, сохранение и удаление данных JSON
- Поддержка светлой и тёмной темы
- Многоязыковая поддержка (английский, русский)

## Использование
1. Скопируйте и вставьте ваши данные JSON в текстовое поле.
2. Нажмите **Визуализировать**, чтобы увидеть данные, отображённые в виде дерева.
3. Вы можете раскрывать/сворачивать объекты и массивы.

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/KotyaraDev/json-visualizer.git
```
2. Установите зависимости:
```bash
npm install
```
3. Запустите приложение:
```bash
npm start
```
